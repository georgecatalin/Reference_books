# Reference Books

A curated collection of compact reference books covering essential IT topics, with a focus on vocabulary, theory, syntax, practical patterns, and edge cases.

## Overview

This repository is intended as a structured knowledge base for quick study, revision, and practical reference.  
The material is organized to make core concepts easy to review without unnecessary detail.

## Scope

The content may include:

- terminology and definitions
- conceptual foundations
- syntax and usage rules
- practical patterns and examples
- edge cases, pitfalls, and exceptions

## Intended Use

This repository is designed for:

- quick lookup
- structured revision
- interview preparation
- continuous learning
- building concise technical reference material

## Organization

Content is grouped by topic, with each reference book aiming to remain concise, practical, and easy to scan.

## Notes

This repository is an evolving collection and will continue to expand over time.
