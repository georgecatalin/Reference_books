#summary

Here's your complete 30-day PHP curriculum. Click any day pill to see exactly what you'll build and practice that day — then hit "Go deep on this day" to start a full lesson with hands-on exercises.

**How this is structured:**

The four phases mirror how real PHP developers actually grow:

**Phase 1 (Days 1–8) — Foundations.** No frameworks, no shortcuts. You'll learn how PHP actually works at the language level — types, arrays, file I/O, error handling. Everything later is built on this.

**Phase 2 (Days 9–17) — Web & Data.** HTTP, forms, MySQL with PDO, sessions, authentication, and security. You'll build a working blog by day 17 using only raw PHP — no framework crutches. This is where most beginners skip corners that later cause real security bugs.

**Phase 3 (Days 18–25) — Architecture.** OOP done right, Composer, building your own MVC from scratch, REST APIs, and your first unit tests. Once you've built MVC by hand, Laravel won't feel like magic — it'll feel familiar.

**Phase 4 (Days 26–30) — Production.** Caching, background jobs, real deployment, a Laravel orientation, and a capstone project you actually ship.

**How to use this roadmap:**

- One day = one focused session (1.5–2 hours of real practice)
- Each day has a deliverable — don't move on without building it
- Click any day above to start that lesson right now
- Come back here whenever you want to jump to a different day or track your progress
